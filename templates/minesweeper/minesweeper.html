MINESWEEPER

A classic puzzle game built with Macroquad

An interactive retro minesweeper experience compiled natively down to WebAssembly (WASM).

Want to run it locally? The desktop code repository is available here on GitHub.

Controls

  • Left Click — Reveal a cell on the grid
  • Right Click — Place / remove a danger flag on a suspected mine
  • R Key — Instant board reset to clear the field and start a new game

Gameplay Rules

  • The board numbers indicate exactly how many mines are touching that specific square.
  • Uncover all safe spaces without detonating a single mine to win the match.
  • Use strategic reasoning to systematically flag absolute mine coordinates before blind clicking.
